# LongTake — Anonymous Supplementary Material

Anonymous Authors

Serve this directory over HTTP and open index.html. All videos, figures, fonts, and playback libraries are included locally. No account or external media service is needed.

This supplement contains 36 gallery examples for each of the 30-second and 60-second settings, matched comparisons, teacher comparisons, and the conditional-guidance ablation. Muted videos play automatically while visible and pause off screen. Manual pause, 1×, 2×, 5× and seeking are available.
